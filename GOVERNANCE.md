# Governance (draft)

This is a draft for the founding group to edit.

## Roles

- **Maintainers:** review and merge pull requests, keep the Bill of Materials accurate, and run the project board. There should always be at least two.
- **Site steward:** responsible for one physical box. Runs the check rota for that box.
- **Site host:** the organization whose property the box sits on. The host can veto any change to a box on its property.
- **Contributors:** everyone else. No permission needed to open issues or pull requests.

## How decisions are made

- Small changes: one maintainer approves.
- Changes to the standard module size, the swap rules, or anything involving a camera, a lock, or a battery: open an `rfc` issue, leave it open for at least seven days, then two maintainers approve.
- Changes to a physical box: the site steward and the site host must both agree.

## Other boxes

Anyone may build their own box from these plans. To be listed here as a sister box, name a site steward and follow the swap rules.
