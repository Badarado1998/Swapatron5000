# Project kit wishlist

**A "kit" is a small bundle of parts that lets one person start one kind of work.** Camera brief? Here is a bench kit for it. Power budget? Here is a kit for that.

> **Nothing is decided yet.** This is a wishlist, not a shopping list. Quantities are blank on purpose, because the designs are not chosen. Nothing here is a part number or a price. Everything is for **bench testing**, not for the box.

The list is in [kits.csv](kits.csv). It follows the same columns as the main [wishlist](BOM.csv), so a spreadsheet opens both.

## The kits

| Kit | For which door | What it lets someone do |
|---|---|---|
| Camera bench kit | [Camera](../integrations/camera/README.md) | Test whether a camera is needed at all, and how to keep it safe |
| Inventory kit | [Inventory](../integrations/inventory/README.md) | Test took-and-left, door, and weight counting |
| Power bench kit | [Solar and power](../integrations/solar/README.md) | Measure what devices really use, and what a cold box does |
| Safety sensor kit | [Safety](../integrations/safety/README.md) | Compare sensors for damp, heat, leaks, and tampering |
| Security bench kit | [Security](../integrations/security/README.md) | Test lock and tamper ideas on a bench |
| Discovery kit | [Discovery](../integrations/discovery/README.md) | Test range and how devices find each other |
| Gateway kit | [Discovery](../integrations/discovery/README.md) | Give the box's devices a way out to the network |
| Visitor starter kit | [The box](../README.md) | The bags, cards, and stickers that visitors take home |
| Petting zoo kit | [Petting zoo](../docs/petting-zoo.md) | Run the hands-on zoo |
| Contributor bench kit | Everyone | Basic tools to lend |
| Drawing kit | [Drawings](../hardware/designs/README.md) | Sketch days |

## How to give

1. Find an item in [kits.csv](kits.csv).
2. [Pledge it](../../../issues/new?template=pledge-a-part.yml) and say which kit.
3. **Hold on to it.** Please do not ship or drop anything off yet. Physical drop-off waits for the lab to confirm.
4. Used and working is fine. Kits are bench gear, so they do not have to be new.

## How to lend

Some of this is better lent than given. Tools, meters, and test boards can go to the person who has the next brief. Open a pledge and say "lend". It is the same promise as the box: take it, build something, pass it on.

## Kit stewards

Every kit needs a steward who knows what is in it and who has it. This is a good job for a person who likes lists. See the "Supplies keeper" role on the [founding team](../docs/founding-team.md).

## Not on the list?

[Open an idea](../../../issues/new?template=idea.yml) with the title "Kit: ". Good kits get added.
