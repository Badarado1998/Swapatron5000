# Screens

Wireframes, mockups, and clickable pages for the box live here, one folder per screen.

## How to add one

1. Make a folder named for the screen, for example `qr-landing`.
2. Put your files in it. For a clickable page, use a single `index.html` with no outside dependencies and no tracking.
3. Add a `README.md` based on the [screen brief template](../templates/screen-brief.md).
4. Open a pull request, or post the files on an issue and a maintainer will add them.

Nothing here is the chosen design. Every screen is an idea to react to, and every screen must work with no login.
