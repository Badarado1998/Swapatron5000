# Swapatron-speak

**A field guide to IoT lingo, translated into plain English, with cute names for the critters.**

Everything in this project is written plainly first. The cute names are for fun, and for learning. If a joke ever gets between you and the next step, ignore the joke and read the plain version.

## Critters and their habitats

| Real term | Swapatron-speak | What it really means |
|---|---|---|
| IoT device | Critter | A small gadget with a sensor, a processor, or a radio that can talk to other gadgets |
| Node | A critter in the herd | One device in a network |
| Gateway | The gate | The device that connects your critters to the wider internet |
| Mesh network | The herd | Devices that pass messages along to each other, so the message can hop around obstacles |
| Edge device | An outdoor critter | A device that lives out in the world, not in a server room |
| Dev board | A hatchling | A small ready-made circuit board for trying out ideas |
| Microcontroller | The little brain | The small chip that runs a gadget's program |
| Breadboard | The nursery | A board where you plug parts together without soldering |
| Jumper wire | A vine | A short wire that connects two points on a breadboard |
| Pins (GPIO) | Paws | The connection points on a board that can read or control things |

## Senses and abilities

| Real term | Swapatron-speak | What it really means |
|---|---|---|
| Sensor | A sense | A part that measures something, like heat, light, or moisture |
| Actuator | A limb | A part that does something, like a motor, a buzzer, or a relay |
| LED | A blinky | A small light that turns on and off |
| Servo | A little arm | A small motor that moves to a set angle |
| Bluetooth Low Energy | Whispering | Short range, low power radio |
| LoRa | Howling | Long range, low power radio that sends small messages a long way |
| Wi-Fi | Chatting | Fast radio that connects to your network |

## How critters behave

| Real term | Swapatron-speak | What it really means |
|---|---|---|
| Firmware | Instincts | The program stored on the device |
| Flashing | Teaching a new trick | Loading new firmware onto a device |
| OTA update | A vet visit with no needle | Updating firmware over the air, without plugging in |
| Bootloader | Waking up | The small program that starts the main one |
| Sleep mode | Nap time | Using very little power while waiting |
| Reset | A fresh start | Restarting the device |
| Pairing | Making friends | Two devices agreeing to talk to each other |
| Handshake | Introductions | The first exchange that sets up a connection |
| Ping | A tap on the shoulder | A small message that asks "are you there?" |
| Packet | A little letter | A small chunk of data sent over a network |
| Payload | What it is carrying | The useful data inside a packet |
| Heartbeat | "I'm alive" | A message sent at regular times to show a device is working |
| Latency | How long it takes to answer | The delay between asking and getting a reply |
| Watchdog timer | The watchdog | A timer that restarts a device if it gets stuck |
| Brownout | Feeling faint | When the power drops low enough that a device misbehaves |
| Debugging | Finding what is bugging it | Tracking down why a program is not doing what you expect |
| Prototype | A hatchling | The first rough version of something |

## Swapatron's own words

| Word | What it means |
|---|---|
| **Feed it** | Leave a part in the box |
| **It passes it on** | Someone takes the part and uses it |
| **Hatched** | Built and open. Not yet, and nothing is decided |
| **Keeper** | A volunteer who looks after the box |
| **Understudy** | A kid learning alongside an adult |
| **Critter Clinic** | A bench where a volunteer helps you with a stuck board |
| **Technology petting zoo** | A hands-on table of friendly gadgets. See [the petting zoo](petting-zoo.md) |
