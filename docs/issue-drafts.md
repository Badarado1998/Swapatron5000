## RFC: Should the box unlock through GitHub?

**The proposal**

The box door stays locked. To open it, a person scans the QR code, signs in with GitHub, and taps "Unlock".

**Why**

- Some accountability for who opens the box
- It confirms the person knows GitHub, which is where most projects for these parts live
- It gives every visitor a path into the project

**Concerns to solve**

- **Kids under 13** can not have a GitHub account. How do they use the box? Ideas: an adult's account, a code from the lab front desk, or one bin that is always open.
- **No phone, no signal, or GitHub is down.** What happens? The lock must never trap anything, and must have a manual key override.
- **Power.** A lock needs power all year. This depends on the solar and battery module.
- **Privacy.** An unlock log is a record of who visited and when. What do we keep, for how long, and who can see it? This must be on the sign.
- **How much accountability is it really?** A GitHub account is free and can be anonymous. Should we require an account of a minimum age, or one earlier contribution?
- **Friction.** Fewer casual visitors will use the box. Is that an acceptable trade?

**Options**

1. No lock. A weather latch only.
2. Lock the whole box behind a GitHub sign-in.
3. Open bins stay unlocked. Only the sealed bin with higher value boards unlocks through GitHub.
4. Start with option 1, measure loss for three months, then decide.

**What we need from you**

Vote with a thumbs up on a comment for the option you prefer, or propose another. If you can design the lock hardware or the sign-in service, say so.

**Fixed points, not up for a vote**

- The site host must approve any lock.
- There must be a physical key override held by the stewards.
- No camera is part of this proposal.

## RFC: How should we share batteries safely?

**The need**

Makers nearby have a hard time finding small batteries, especially lithium cells. We would like the project to help.

**Fixed points, not up for a vote**

- No loose lithium cells in the outdoor box. The U.S. Consumer Product Safety Commission warns consumers against buying or using loose 18650 cells.
- No battery charging in the outdoor box. Lithium-ion cells must not be charged below freezing, and a closed box in summer sun can get too hot.
- No collection of used or damaged batteries. We will point people to an existing recycling drop-off.
- The site host must approve any battery storage on its property.

**Open questions**

1. Can we run an indoor battery shelf at the lab, at room temperature, during open hours? Who would look after it?
2. Which forms are acceptable to share? Ideas: new cells in sealed retail packaging, protected cells from known brands, cells in holders with covered terminals, finished packs with a protection circuit.
3. How do we test and label a donated cell? Or do we accept new cells only?
4. Should the outdoor box carry sealed packs of AA and AAA alkaline or NiMH cells?
5. What should the sign say to send people inside for lithium cells?
6. Where is the nearest battery recycling drop-off we can point to?

**What we need from you**

If you work with batteries professionally, we especially want your review. Comment with answers, corrections, or designs.
