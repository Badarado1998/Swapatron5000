# Box design team

We design the physical box: the shell, the bins, the mount, and the sign.

> **Draft. Nothing here is decided.** This page is a starting point for discussion. See [DECISIONS.md](../DECISIONS.md) and [how to have your say](../docs/have-your-say.md).

## You do not need CAD

Pick the way that suits you. All three count.

| Level | How | Tools |
|---|---|---|
| 1. Sketch | Draw it on paper, take a photo, and [share your sketch](../../../issues/new?template=design-sketch.yml) | Pencil and a phone |
| 2. React | Comment on other people's sketches. Add a thumbs up to the ones you like | A GitHub account |
| 3. Model | Add CAD, laser, or 3D print files to `hardware/designs/your-design-name/` in a pull request | Any CAD tool. Please include an open format such as STEP, SVG, or DXF |

## The design brief (proposed)

This is a starting brief, and it is open for comment like everything else. Sketches that follow it are easier to build, but sketches that challenge it are welcome too.

**Must have**

- Keeps rain out: sloped roof with an overhang, door facing away from the weather
- Lets damp air out: screened vents, so the inside does not fog up
- Two zones inside: a sealed bin for boards and chips, and open bins for wire and hardware
- Built around one standard bin size, so anyone can add a matching module
- Reachable by kids and by wheelchair users
- A clear sign and a QR code on the front
- No sharp edges and no pinch points
- Buildable in one day with common tools

**Nice to have**

- A clear door, so people can see inside before opening
- Room to bolt on extra modules later
- A dry spot for a small electronics enclosure, for Phase 5
- Made from materials that can be donated or reclaimed

**Proposed safety limits**

- Mains power
- Anything that blocks a walkway

## Open questions

These are waiting for someone to pick them up.

1. Which gasketed bin should be the standard? It needs to be cheap, easy to buy, and likely to stay on sale for years.
2. Post mount or wall mount? This depends on what the site host approves.
3. Cedar, HDPE, or exterior plywood for the shell?
4. How do add-on modules attach?

## How a design gets picked

Sketches are open now, until Sunday, February 21, 2027. Between February 22 and March 14, the maintainers and the site host propose one design, or a mix of several, explain why, and take final comments. The chosen design becomes the cut list and the wishlist. See the [timeline](../ROADMAP.md).
