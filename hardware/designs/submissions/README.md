# Submissions

Drawings that people have turned into files live here, one folder per drawing.

## How to add one

1. Make a folder named `your-username-short-name`, for example `octocat-roof-overhang`.
2. Put your drawing in it as an SVG, PNG, or PDF. SVG is best, because it is easy to review.
3. Add a short `README.md` using the template below.
4. Open a pull request. [Learn GitHub](../../../docs/learn-github.md) shows how. If you would rather not, post the files on an issue and a maintainer will add them.

## Template for your README

```
# Name of your drawing

**By:** your GitHub username
**AI-assisted:** yes or no
**Which wanted view:** number from WANTED.md, or "my own idea"
**What it shows:** one or two sentences
**Sizes:** guesses or measured? Say which
**Unsure about:** what you want others to check
**License:** CC-BY-SA-4.0 (documents and art) or CERN-OHL-S-2.0 (hardware designs)
```

Nothing here is the chosen design. Every submission is an idea.
